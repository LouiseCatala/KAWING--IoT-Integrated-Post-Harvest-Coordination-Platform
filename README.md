## About the Project

**KAWING** (Knowledge-based Agricultural Workflow Integration Network Gateway) is an IoT-integrated, web-based post-harvest coordination platform designed to support rice farmers in Magalang, Pampanga. The project aims to connect farmers with buyers, traders, and agricultural logistics service providers through a centralized platform.

The system includes **PalaySense**, an IoT-based grain moisture assessment device, and a **community access kiosk** to support farmers who need assisted access to the platform.

## Key Features

- **Harvest Marketplace** – Allows farmers to post harvest information and review buyer offers.
- **Post-Harvest Service Coordination** – Helps connect farmers with transportation, drying, storage, and milling service providers.
- **PalaySense Integration** – Displays grain moisture readings and corresponding classifications.
- **Community Access Kiosk** – Provides an additional way for farmers to access KAWING.
- **Administrative Dashboard** – Supports account approvals, record monitoring, announcements, and reports.

## Technology Overview

- **Frontend:** React, TypeScript, Vite
- **Backend:** PHP API
- **Database:** MariaDB
- **IoT Hardware:** ESP32-based PalaySense device
- **Access:** Web interface and community kiosk
