# Service Requests Price Offers Style Design

## Intent

Make My Service Requests visually consistent with Price Offers Received so the farmer module feels like one product.

## Approved Direction

- Reuse the Price Offers page hierarchy: emerald title card, actions inside the title card, full-width two-tab selector, and a responsive three-column card grid.
- Match its spacing, typography, borders, shadows, status badges, and inner information surface.
- Preserve Posted Requests as the default, Accepted Services filtering, all request data, and every workflow action.
- Do not add gradients or backend changes.

## Approach

Directly reuse the established Price Offers visual pattern. A separate new design was rejected because the user explicitly requested a match.
